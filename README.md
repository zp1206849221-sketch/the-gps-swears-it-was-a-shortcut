# The GPS Swears It Was a Shortcut

A tiny Python program that writes the GPS's own excuse — delivered in that calm, unbothered navigation voice — for sending the driver down the wrong road. No apology, no doubt: the road was wrong.

## Run

```sh
python3 main.py
```

This creates `/output/entry.txt` containing the single-line excuse (1–200 characters, UTF-8).
